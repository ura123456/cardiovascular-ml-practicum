## 7. Cara Menjalankan Proyek

1. Clone repository ke komputer lokal.
2. Buat virtual environment Python.
3. Aktifkan virtual environment.
4. Instal library yang dibutuhkan menggunakan `requirements.txt`.
5. Unduh dataset dari Kaggle dan letakkan file `cardio_train.csv` di direktori `data/raw/`.
6. Jalankan notebook secara berurutan mulai dari notebook 01 hingga 04.

Contoh instalasi library:

```bash
pip install -r requirements.txt
```

**Catatan:** Pastikan dataset telah tersedia di lokasi yang sesuai sebelum menjalankan notebook.
